## 0. 직접 확인한 수치·구조 (이 문서 후보들의 근거)

**Ten Minute Physics (Matthias Müller, MIT) — 소스코드 raw 확인 [검증]**
- 천 `14-cloth.html`: dt=1/60, `numSubsteps=15`, 중력 −10, 신축 compliance=0(완전 강성), 굽힘 compliance 기본 1.0(슬라이더 0~10). 공통식 `alpha = compliance/dt/dt; s = -C/(w+alpha)`. 서브스텝 순서 = preSolve(속도+중력 → prevPos 저장 → 위치 갱신 → 바닥 클램프) → solve(stretch → bend) → postSolve(`v=(pos-prevPos)/dt`). 위 구간(전체 259k자 중 앞 100k자)에는 구 충돌 없음(바닥뿐), 뒷부분 미확인.
- 자기충돌 `15-selfCollision.html`: 해시 `tableSize=5*N`, 이웃목록은 **프레임당 1회**(`maxTravelDist = maxVelocity*frameDt`), `maxVelocity = 0.2*thickness/dt` 로 속도 클램프, 쌍 필터 `if (dist2 > restDist2) continue`(떨어져 있는 쌍 스킵), 시작 시 thickness 보다 가까운 쌍은 `minDist = 휴지거리`, 보정은 양쪽 0.5씩, 서브스텝 10.
- 소프트바디 `10-softBodies.html`: 서브스텝 10, 엣지 compliance 기본 100(슬라이더×50), 부피 compliance 0, 제약 `C = vol − restVol`, 사면체 부피 = `dot(...)/6`, 면 그래디언트 = 두 엣지 외적/6, 메시는 하드코딩 토끼(`tetIds`/`tetEdgeIds`/`tetSurfaceTriIds`).
- 강체 `22-rigidBodies.html`: 형상 box/sphere 뿐, 제약은 거리 제약뿐(**충돌 검사 없음**), 서브스텝 10·반복 1, 쿼터니언 `rot.w += 0.5*dt*dRot.w; normalize`. 장면 = "크립 모빌"(단방향 줄 `unilateral`, compliance 0, 5단 트리) / 체인(박스 4개, 크기비 cbrt(2), compliance 0.001, damping 5.0).
- 조인트 `25-joints.html`: 타입 hinge/ball/prismatic/cylinder/servo/motor/fixed, 풀이 순서 position → orientation → velocity update → damping, 각도 한계는 `phi = clamp(phi,min,max)` 후 `cross(ra,b)` 보정.
- 높이장 물 `20-heightFieldWater.html`: `waveSpeed = min(waveSpeed, 0.5*spacing/dt)` 안정 조건, `c = waveSpeed²/spacing²`, `v += dt*c*(sumH − 4h)`, `h += (0.25*sumH − h)*pd`, 부유체 결합 `alpha=0.5`, 부력 = 잠긴 기둥 부피 × 중력. spacing 0.02·dt=1/30 이면 선언 속도 2.0 이 0.3 으로 **조용히 깎임**.
- 에피소드 목록(25편, 데모 URL 규칙 `…/tenMinutePhysics/<NN>-<name>.html`): https://matthias-research.github.io/pages/tenMinutePhysics/index.html [검증]

**찢어지는 천 원형 (suffick 2013) — gist 소스 확인 [검증]**: 51×31 격자, `physics_accuracy=5`, `spacing=7`, `tear_distance=60`, `gravity=1200`, Verlet 감쇠 `0.99`, 마우스 영향 반경 20(드래그 1.8배), 절단 반경 5, 제약 길이가 60 넘으면 `remove_constraint`.

**XPBD 정식 [검증, zenn 해설]**: `α̃ = α/Δt²`, `Δλ = (−C − α̃λ)/(∇C·M⁻¹·∇Cᵀ + α̃)`, `Δx = M⁻¹∇Cᵀ Δλ`. Small Steps(Macklin 2019): "n 반복 1스텝보다 n 서브스텝 1반복이 낫다" [검색요약 확인, 원문 PDF 403].

**Solver2D / Box2D 3.0 (Erin Catto 2024) [검증]**: PGS_Baumgarte(지터 위험) / PGS_NGS / +Block / PGS_Soft / TGS_Sticky(서브스텝+마찰 앵커, 스택은 안정, 접선 진동) / **TGS_Soft = Soft Step(채택)** / XPBD(마찰 어렵고 원점에서 멀면 반올림 오차로 물체가 뜸 → deltaPosition 정식으로 해결). Soft Step 은 Hertz 를 스텝 주파수보다 훨씬 낮게(60Hz 스텝에 ≤30Hz) 둔다.

**Jakobsen "Advanced Character Physics" (Hitman) [검증]**: Verlet(`x_new ≈ 2x − x* + a·dt²`), 제약 이완 반복, 천은 보통 1패스, 강체(사면체=입자 4+거리제약 6)는 3~4패스, 래그돌=막대 제약, 관절 한계=내적 제약, 자기충돌=단방향 거리 제약. 주의: 제한 반복이라 "약간 물렁"이 정상.

**H2-02 XPBD 천 + 커서 구 + 자기충돌** ★5
- 보이는 것: 커서가 구(球)가 되어 천을 밀어 올리면 천이 구 위에 흘러내려 주름이 지고, 자기 자신과 겹쳐도 뚫리지 않는다.
- 알고리즘: XPBD 신축(compliance 0)+굽힘(대향 정점 거리, 기본 1.0) [검증] + 구 투영 + 공간해시 자기충돌(휴지거리 필터, `0.2·thickness/dt` 속도 클램프) [검증]. 서브스텝 15 [검증].

- 축소: 20×20(400), 서브스텝 8, 자기충돌 반경 내 이웃만(브루트포스 400²/2=8만이라 해시 필수 → 격자 셀 정수 키), 구 충돌은 해시 불필요.

**H2-05 Cosserat 로프 (꼬임·트위스트 케이블)** ★5

- 보이는 것: 슬링키가 계단 위에서 뒤집혀 한 칸씩 내려간다.

- 축소: 측면 2D 고리 체인 30개.
- 출처: https://ar5iv.labs.arxiv.org/html/1403.6809 (검색요약)

### B. 소프트바디

**H2-10 압력 풍선 (Matyka 압력 모델)** ★4
- 보이는 것: 공기가 찬 풍선/젤리 공이 눌리면 부피가 보존돼 옆으로 부풀고, 놓으면 팽팽히 튕겨 복원. 구멍 내면 바람 빠짐(압력 제거).
- 알고리즘: 스프링-질점 + 압력력. 이상기체 상태식 `p = nRT/V`(Clausius–Clapeyron), 부피는 Gauss 정리(2D: 신발끈 면적 `A=½Σ(xᵢyᵢ₊₁ − xᵢ₊₁yᵢ)`), 엣지 힘 = `p·길이·외향 법선` — 추력 분배는 [검증: 목차/초록], 2D 식은 (추정).
- 어려움: 압력 항이 양의 되먹임(부피↓ → 압력↑) 이라 강성 큰 스프링과 만나면 발산, Heun/RK2 필요(원 자료도 Heun 절 존재 [검증 목차]).
- 축소: 정점 40~60, 서브스텝 8.
- 출처: https://arxiv.org/abs/physics/0407003 , https://panoramx.ift.uni.wroc.pl/~maq/soft2d/index.php [검증(초록/목차)]
- 중복: **부분 중복 s086**(Verlet 스프링 젤리). 압력(부피 보존)이 핵심 차별점이라 별건으로 인정 가능.

**H2-11 형상 매칭 젤리 (Meshless Shape Matching)** ★4
- 보이는 것: 변형돼도 "원래 모양으로 돌아가려는 의지"가 있는 점구름 젤리/푸딩. 스프링이 없어 찢겨도 모양 복원.
- 알고리즘: 질량중심 정렬 → `A_pq = Σ m(p−c)(q−c₀)ᵀ` → 극분해로 회전 R → 목표 `g = R(q−c₀)+c` → `x += α(g − x)` (Müller 2005). 2D 는 `θ = atan2(A₁₀−A₀₁, A₀₀+A₁₁)` 닫힌 해(추정 유도).
- 어려움: 반전(역전된 형태)에서 극분해 불안정, α 가 크면 에너지 주입. 선형/이차 변형 모드 선택.
- 축소: 점 24~40, 반복 없음(해석적).
- 출처: https://cg.informatik.uni-freiburg.de/publications/2005_SIGGRAPH_deformationShapeMatching.pdf [검색요약]
- 중복: **부분 중복 s086**(둘 다 말랑 소프트바디). 알고리즘이 다르므로 같은 장면에 두지 말고 대상을 바꿔야 함(예: 푸딩 → 로고 글자 젤리).

**H2-12 XPBD 사면체 푸딩 (부피 보존)** ★5

**H2-22 오리가미 시뮬레이터 (bar-and-hinge)** ★5
- 보이는 것: 평평한 접기선 패턴(미우라/물폭탄/학)이 스크롤 진행도 0→1 로 모든 주름이 **동시에** 접히며 3D 입체가 된다. 면은 약간 휘어지며 재료감 있음.
- 알고리즘: 삼각 메시, 노드 = 질점, 제약 3종 — 축(엣지 길이)·면(삼각형 각)·접기선(이면각 목표 `ρ_target·t`)의 컴플라이언트 명시적 적분, GPU 프래그먼트 셰이더로 병렬 [검증: 논문 초록/README]. 모든 접기선을 동시에 푼다 [검증].
- 어려움: 명시적 적분 → 강성 클수록 dt 를 매우 작게(진동), 면 대각 진동, 접기선 각도 목표를 점진 증가시키지 않으면 자기교차(자기충돌 없음이 원 모델 한계, 추정).
- 축소: CPU Float32Array, 노드 ~150–400, 프레임당 서브스텝 20–40(추정), 패턴은 미우라 6×6 등 해석 생성, 렌더 = 면 법선 기반 단색 명암의 Canvas2D 삼각형.
- 출처: https://erikdemaine.org/papers/OrigamiSimulator_Origami7/ [검증(초록)], https://github.com/amandaghassaei/OrigamiSimulator [검증(README 일부)], https://origamisimulator.org/
- 중복: **s080 과 개념 인접**(종이 접힘 메뉴 = 4패널 힌지 운동학, 물리 아님). 다중 접기선 + 탄성 해석은 별건.

**H2-23 미우라 오리 해석 접힘 (강체 접기)** ★4
- 보이는 것: 지그재그 평행사변형 패널이 단 하나의 자유도로 부채·태양전지판처럼 접혀 들어가며 3D 입체 면이 반짝인다.
- 알고리즘: 미우라-오리 기하 파라미터화(접힘 각 θ → 패널 3D 좌표 닫힌 식, 추정: 참고 원본 못 찾음) + 패널 평면 보간.
- 어려움: 닫힌 식 유도, 패널 쌍별 뒷면 순서(painter) 정렬, 두 방향 접기선 교번.
- 축소: 해석해, 패널 6×6=36, 연산 극소.
- 출처: (추정) 미우라 접기 일반 지식. 구현 참고 = H2-22 의 출처.

**H2-24 페이지 컬 물리 (원통 말림)** ★4
- 보이는 것: 책/잡지 모서리를 잡아 끌면 종이가 원통으로 말리며 뒷면이 비치고 놓으면 스프링으로 넘어가거나 복귀한다. 기울기 축 임의.
- 알고리즘: 평면 점 `p` 를 말림축 `a` 로 사영 → 거리 `d` 가 반지름 r 이상이면 원통 위로 `θ = (d−d₀)/r`, 말림 호 `x' = d₀ + r sin θ, z = r(1−cos θ)`, 넘어가면 뒷면 렌더(법선 반전). 원통 방식 [검증: alvarotrigo 설명], 임의 방향 접힘은 정점을 선택축에 사영해 1D 호로 변환 후 재분배 [검증: Codrops 포트폴리오 글].
- 어려움: 뒷면/앞면 z 정렬, 말림 경계의 곡률 불연속(C¹ 처리), 드래그 중 반지름 일정 vs 가변.
- 축소: 메시 40×30, Canvas2D 삼각형 + 법선 밝기.
- 출처: https://alvarotrigo.com/fullPage/page-flip-effect/ , https://tympanus.net/codrops/2025/11/27/letting-the-creative-process-shape-a-webgl-portfolio/ (모두 검색요약)
- 중복: **부분 중복 s080**(종이 접힘 메뉴는 힌지 접기). 컬은 곡면 말림이라 별건.

### F. 메카니즘

**H2-25 인볼류트 기어 트레인 + 유성기어** ★4

**H2-26 시계 탈진기 + 밸런스휠** ★5

- 알고리즘: 밸런스휠 = 비틀림 스프링 진동(주기 일정), 탈진기 = 이빨-팔레트 접촉 이산 사건(충격 + 정지(recoil/dead-beat)), 힘은 주스프링 토크 → 기어열.

**H2-27 캠·제네바·크랭크 머신룸** ★4
- 보이는 것: 캠이 도는 만큼 종동절이 정확한 변위곡선으로 오르내리고, 제네바 구동이 간헐 회전, 크랭크-슬라이더가 피스톤을 민다. 여러 기구가 한 축으로 연동.

### G. 강체·충돌

**H2-28 루브 골드버그 연쇄 (자체 강체 솔버)** ★5
- 보이는 것: 공이 굴러 도미노를 쓰러뜨리고 시소를 때려 다른 공을 쏘아 올려 문 열고... 스크롤/클릭으로 시작되는 긴 연쇄.
- 알고리즘: 폴리곤 SAT 접촉 매니폴드 + sequential impulse(누적 임펄스 클램프, warm starting, 마찰 원뿔) [검증: Catto 2006 슬라이드 제목/Solver2D 설명]. 도미노 속도는 마찰에 크게 좌우, 시뮬에서 연쇄가 중간에 멈추기도 함 [검증: Cantor & Wojtacki 요약].
- 어려움: 스택/도미노 안정성(지터·슬립), 터널링(연속충돌), 이벤트 트리거 시퀀싱(연쇄가 안 이어지면 UX 파괴) → 시드·고정 스텝 필수.
- 축소: 박스 20개 + 원 3개 + 시소 2개, 서브스텝 4, 접촉 매니폴드 단순화(2점).
- 출처: https://box2d.org/files/ErinCatto_SequentialImpulses_GDC2006.pdf , https://github.com/eigenmatt/domino-simulation , https://sciencenews.org/?p=3114727 (검색요약)

**H2-29 강체 스택 안정성 (솔버 3종 AB 비교)** ★5
- 보이는 것: 같은 박스 피라미드를 [나이브 / PGS+Baumgarte / Soft Step] 세 개 나란히 떨어뜨려 하나는 무너지고 하나는 지터, 하나는 서 있는다. 솔버가 곧 비주얼.

- 어려움: 피라미드 안정 = 마찰 앵커/워밍스타트/수면(sleep) 삼박자, XPBD 는 마찰 어렵고 원점에서 멀면 부유 [검증].

### H. 카오스·궤도·파동

**H2-32 진자 파동 (Pendulum Wave)** ★4
- 보이는 것: 15~25개의 진자가 길이 차로 처음엔 일제히 → 뱀처럼 파동 → 무질서 → 다시 정렬되는 반복. 3D 줄·추.
- 알고리즘: 진자 `i` 가 T 안에 `Nᵢ = N₀+i` 번 진동하도록 `Lᵢ = g(T/(2πNᵢ))²` (내 유도, 소규모 진동 가정 [검색요약: 주기식 T=2π√(L/g) 확인]). MathWorks 예: 24개·68~91회·60초, 초기각이 작을수록 재정렬이 정확 [검증(검색요약)].
- 어려움: **비선형(실제 sin θ) 적분은 초기각이 크면 주기가 길어져 재정렬이 깨진다** → 해석(SHM) 위상 vs 수치 적분 선택, 오일러 에너지 드리프트.
- 축소: 해석 위상이면 연산 극소(권장), 수치 적분은 심플렉틱.
- 출처: https://mathworks.com/help//releases/R2021a/physmod/sm/ug/pendulum-waves.html , https://javalab.org/?p=68670 (검색요약)
- 중복: 없음. 난이도 ★3 ~ 4 (시각 대비 구현이 쉬움 → 연출로 승부).

**H2-33 이중 진자 + flip-time 위상 지도** ★5
- 보이는 것: 이중 진자의 궤적 트레일 + 오른쪽에 초기각 (θ₁,θ₂) 평면 전체를 색칠한 **카오스 지도**(뒤집힐 때까지 걸린 시간). 지도 위를 클릭하면 그 초기조건으로 진자가 실행.
- 알고리즘: 라그랑주 운동방정식 + RK4 고정 스텝. 에너지 드리프트 있으므로 에너지 체크 [검증: nullprogram "RK4 가 에너지를 흘림"]. 민감도 시연용 ghost 진자(1e-4 rad 차이) [검증].
- 어려움: 지도 한 픽셀 = 독립 시뮬 → 해상도² × 스텝. 
- 축소: 지도 96×96 = 9216 시뮬 × (뒤집힘까지 ≤300 스텝) ≈ 2.8×10⁶ RK4 → **오프라인 1회 계산 후 캐시**하거나 타일 점진 계산(프레임당 N행, 추정). 
- 출처: https://nullprogram.com/blog/2018/02/15/ , https://inventivehq.com/tools/developer/double-pendulum-simulator , https://github.com/william-popmie/double-pendulum (GPU RK4 위상 지도) (모두 검색요약)
- 중복: 없음.

**H2-34 자기 진자 프랙탈 (3자석 끌개 영역)** ★5
- 보이는 것: 화면 전체 픽셀이 "그 위치에서 진자를 놓으면 어느 자석에 정착하는가"로 3색 칠해지고 경계가 프랙탈. 커서 위치에서 실제 진자가 궤적을 그리며 정착.
- 알고리즘: `a = −k·r − γ·v + Σ_m F_m(r)`, `F ∝ r/|r|³`(+ 연화항), 적분기는 **Beeman**(Verlet 계열), 정지 조건 = 최소 스텝 경과 + 자석 반경 내 + 속도 임계 [검증: beltoforion].
- 어려움: 경계 근처는 작은 오차에 색이 바뀜(수치 민감 = 카오스), 마찰이 너무 크면 구조 소실·너무 작으면 스텝 상한에 걸림, CPU 로 512² 가 수 시간(1994년 수 일, 오늘 브라우저 실시간 [검증]).
- 축소: **프래그먼트 셰이더 불가(소프트웨어 렌더 SwiftShader는 가능하나 느림)** → 128×128 CPU 타일 점진 계산 + 보간 업스케일.
- 출처: https://beltoforion.de/en/magnetic_pendulum [검증], https://gauss.math.yale.edu/fractals/Labs/MagPendulumLab/MagPendulumLab.html
- 중복: 없음.

**H2-35 N-body 바네스-헛 은하 충돌 / 8자 3체** ★4
- 보이는 것: 수천 개 별이 은하 원반으로 회전하다 두 은하가 충돌해 꼬리·나선팔이 뻗는다. 별도 장면으로 8자 궤도 3체가 트레일을 그린다.
- 알고리즘: 쿼드트리 + θ 기준(원거리 근사), leapfrog(심플렉틱) [검증: chkob 저장소 — 100k 입자, N<50 이면 브루트포스가 빠름]. 8자 3체 주기 ≈ 9.2371(G=1, 질량 1) [검증: 2013 논문 요약].
- 어려움: 근접 조우 시 소프트닝 `ε` 없으면 폭발, 시간 스텝 적응, 은하 원반 초기 속도 `v=√(GM/r)` 설정.
- 축소: 별 1500~2500, θ=0.7, 쿼드트리 매 프레임 재구성(메모리 풀), 점 렌더(`fillRect`).
- 출처: https://github.com/chkob/barnes-hut-tree-n-body-implementation-in-html-js , https://arxiv.org/pdf/1302.0912 (검색요약)
- 중복: 부분: s088(중력 렌즈 격자), s085(별 네트워크) 와 소재만 인접. 알고리즘 별건.

**H2-36 Chladni 모래 패턴** ★4
- 보이는 것: 진동판 위 모래 수천 알이 주파수를 바꿀 때마다 절선(진동 0)으로 모여 기하 무늬를 만든다. 주파수 슬라이더·스크롤 연동.
- 알고리즘: 모드 `u(x,y) = sin(nπx/L)sin(mπy/L) ∓ sin(mπx/L)sin(nπy/L)`(자유 경계 가까운 형태, 합성은 추정), 입자는 진폭이 큰 곳에서 랜덤 점프, 절선에서 정지 → 확률적 이동 [검증: 원리 요약]. 정확 공식은 원판=베셀 `J_m(kr)cos(mθ)` [검색요약].
- 어려움: 확산이 느려 수렴 장면이 늦음, 모드 전환 시 입자 재분배 속도.
- 축소: 입자 6k, 점 fillRect, 모드 5종 미리 계산.
- 출처: https://21st.dev/@daiwiikharihar/components/chladni-acoustic-grid.md , https://flavortown.hackclub.com/projects/20206 (12k 입자 사례), https://web3.arxiv.org/pdf/1308.5523 (검색요약)
- 중복: 없음(파동군과 다른 팀과 중복 가능 → 다른 H 조사와 대조 필요).

**H2-37 높이장 물 + 부유체** ★4
- 보이는 것: 물 표면에 공/상자가 떠 있고, 떨어지는 물체가 파문을 만들며 부유체가 출렁인다.
- 알고리즘: 2D 격자 높이 `h`, 속도 `v += dt·c·(Σ이웃 − 4h)`, 감쇠, **파속 상한 `≤ 0.5·spacing/dt`**, 부력 = 잠긴 기둥 부피×중력, 물체가 밀어낸 높이를 표면에 되먹임(`alpha=0.5`) [검증, 소스].
- 어려움: 안정 조건이 파속을 조용히 깎음(선언 2.0 → 실효 0.3 [검증]), 같은 루프 안 읽기-쓰기 순서 의존, 굴절 렌더.
- 축소: 1D 단면(120칸)이면 연산 극소, 또는 2D 60×40.
- 출처: https://matthias-research.github.io/pages/tenMinutePhysics/20-heightFieldWater.html [검증(raw)]
- 중복: 부분: s059(SVG 액체 게이지)는 사인 파형 연출 — 물리 PDE 아님 → 별건.

**H2-38 조인트 기계 (굴삭기·서보·모터 힌지)** ★5
- 보이는 것: 힌지·프리즈매틱·서보 관절로 이어진 굴삭기/크레인 팔이 키보드·스크롤로 움직여 상자를 집고 옮긴다.
- 알고리즘: 강체 + 조인트 풀이 순서 position → orientation → velocity → damping, 각도 한계 clamp, 모터/서보 목표각 [검증, 소스].
- 어려움: 쿼터니언 보정 부호, 한계 도달 시 진동, 질량비 큰 체인.
- 축소: 2D(회전 1축)로 환원하면 쿼터니언 불필요 → 강체 6~8개.
- 출처: https://matthias-research.github.io/pages/tenMinutePhysics/25-joints.html [검증(raw)]
- 중복: 없음. 구현량 큼.

**H2-39 크립 모빌 (균형 매달린 트리)** ★4
- 보이는 것: 천장에 매달린 5단 모빌이 서로 균형을 맞춰 느리게 회전하고, 커서가 건드리면 전체가 미세 진동하며 다시 균형.
- 알고리즘: 강체 막대·구 + **단방향 줄(당길 때만 작동), compliance 0**, 서브스텝 10·반복 1 [검증: 22-rigidBodies 크립 모빌 장면].
- 어려움: 단방향 제약 on/off 전환 시 지터, 3D 쿼터니언 관성 → 2D 환원 시 쉬움.
- 축소: 2D 측면 5단 = 막대 5 + 구 6.
- 출처: https://matthias-research.github.io/pages/tenMinutePhysics/22-rigidBodies.html [검증(raw)]
- 중복: 없음.

## 3. 수치 함정 일반 (여러 후보 공통)

1. **PBD 강성이 반복수·dt 에 종속**(고전 PBD) → XPBD 의 `α̃=α/Δt²` 로 해결 [검증]. 서브스텝 1반복이 큰 스텝 n반복보다 낫다(Small Steps).
2. **고정 dt 필수**: 가변 dt 는 Verlet 속도 불일치·파속 안정조건(`c·dt/h ≤ 0.5` [검증]) 파괴.
3. **터널링**: 속도 상한 `0.2·thickness/dt` 방식 [검증, 자기충돌] 또는 서브스텝.
4. **XPBD 는 원점에서 멀면 반올림 오차** [검증, Solver2D] → 좌표를 화면 중앙 기준으로.
5. **카오스 계열(H2-33/34)** 은 부동소수 오차가 색을 바꾼다 → 스크린샷 비교형 검증은 같은 브라우저·같은 스텝수로만 가능, 시드 고정.
6. **RK4 도 장시간 에너지 드리프트** [검증, nullprogram + 2025 비교 요약] → 심플렉틱(leapfrog/Verlet) 또는 에너지 감시.
7. **이웃 해시 키 충돌/테이블 크기**: `5*N` 사용 [검증].
