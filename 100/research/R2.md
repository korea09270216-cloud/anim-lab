### #01 셰이프 인지 ASCII 렌더러

### #04 레이어드 줌 스크롤 (Telescope 류)
- 모션: 스크롤하면 떠 있던 분해된 이미지 그리드가 Z축으로 다가오고, 가운데 마스크된 메인 비주얼이 분할 텍스트 사이에서 뒤따라 줌되며 레이어 깊이감이 생긴다.

## 4. 구현 시 주의 (라이브러리 환경 기준)
- ScrollSmoother 는 Lenis 와 병용 불가. Lenis 를 쓰는 섹션에서는 요소별 gsap.quickTo 로 lag 구현.
- backdrop-filter + SVG 필터(#07, #16, #26)는 헤드리스 소프트웨어 렌더에서 프레임 급락 — 레이어 수·영역 축소, 정적 스냅샷 캡처 위주로 검증.
- 이미지 에셋 불가 → #02, #08, #11, #20, #35 는 canvas 생성 그라디언트/텍스트를 텍스처로 사용.
- 오디오(#10)는 사용자 제스처 필요, 헤드리스 검증 불가 → LFO 폴백 필수.
