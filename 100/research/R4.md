### F1. Scroll-driven animations (`animation-timeline: scroll() / view()`, `animation-range`)
- Chromium: **115+** (Edge 115). Safari 26.0 지원. Firefox는 stable에서 플래그 뒤(소스마다 상충, 미확정). 151 OK.
- 문법:
  ```css
  .el { animation: reveal linear both; animation-timeline: view(); animation-range: entry 0% cover 40%; }
  .bar { animation: grow linear; animation-timeline: scroll(root block); }
  ```
- 범위 키워드 6종: cover / contain / entry / exit / entry-crossing / exit-crossing (viewport보다 큰 요소는 `-crossing` 사용). 문서 간 crossing 기준 변 설명이 엇갈림 → MDN 시각화 도구로 실측 필요.
- 폴백: `@supports (animation-timeline: scroll())` + `prefers-reduced-motion: no-preference`로 감쌈. 미지원이면 정적 최종 상태.
- 아이디어: 진행바, 카드 리빌, 패럴랙스, 가로 스크롤 섹션, 코버플로우(S1~S10).
- 출처: https://developer.chrome.com/docs/css-ui/scroll-driven-animations , https://tympanus.net/codrops/?p=75216 , https://webkit.org/blog/17101/a-guide-to-scroll-driven-animations-with-just-css/ , https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations/Timeline_range_names , https://webkit.org/?p=17184

### F3. Scroll-triggered animations (`timeline-trigger`, `animation-trigger`, `trigger-scope`)
- Chromium: **145** 예정으로 공지(일부 소스는 146). 151이면 포함 가능성이 높으나 **로컬 151에서 CSS.supports로 실측 필요**.
- 문법(Chrome 블로그 원문):

- 아이디어: 진입 시 한 번 재생되는 고급 리빌(S12), 되감기 가능한 카운터.

## C. 구현 시 공통 주의 (이 프로젝트 규칙과 부딪히는 점)

1. **단위**: 치수는 `calc(var(--px)*N)`. `view()` 오프셋/`animation-range`의 `%`는 타임라인 단위라 규칙 대상 아님. `translateX(-100%)`류 `%`는 transform 안이라 허용 가능성이 높으나 css-check 실제 반응 확인 필요.
2. **transform 소유**: 프로젝트 규칙상 "애니메이션 대상 transform은 GSAP 단독 소유"인데 이번엔 GSAP를 쓰지 않으므로, 개별 속성(`translate`/`rotate`/`scale`)으로 분리해 쓰면 충돌 면적이 줄어든다.
3. **PC/모바일 토글은 library 유틸 클래스**(원칙 11)와 `animation-timeline` 사용은 무관. 단 scroll-driven 진행 구간(`animation-range`)은 모바일에서 별도 조정 필요.
4. **검증(Playwright)**: scroll-driven은 `window.scrollTo`(+ `scroll-behavior:auto` 확인)로 샘플링. 헤드리스에서 `backdrop-filter:url()`·popover top-layer는 캡처가 달라질 수 있으니 DOM·computedStyle 병행(메모리 "헤드리스 고스트" 참고). 실측 전에는 `CSS.supports()`로 F3(`timeline-trigger`), F5(nested), F13, F14, F15를 151에서 한 번 확인할 것.
5. **`random()`은 Chrome 156 예정 → 151 불가**. 아이디어에 넣지 않았다.
6. **기존 항목과의 관계**: 100개 중 CSS 전용은 033(mask radial-gradient), 071~080(CSS3D 일부)이 있으나 모두 GSAP/JS 구동. 이번 후보는 *브라우저 타임라인이 구동*한다는 점에서 계열이 다르다.
7. **미확정/상충 항목(결과 신뢰도 낮음)**: Firefox의 scroll-driven 상태(소스 상충), `entry-crossing`/`exit-crossing`의 기준 변 설명(MDN vs uni-app 상충), F3의 정확 버전(145 vs 146), `timeline-scope` 최초 버전, `ray()`/`offset-position` 최초 버전, `abs()`를 `sibling-index()` 딜레이에 쓰는 구문. → 구현 전 Playwright 151에서 실측.
