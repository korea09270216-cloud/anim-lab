# R1 — 프랜차이즈 창업문의 섹션·인터랙션 레퍼런스 리서치

조사일 2026-10-26. 서브에이전트 3팀(국내 공식 페이지 / 해외 공식 페이지+Awwwards / 전환 아티클)이 WebSearch·WebFetch·원본 HTML(curl)로 조사한 결과를 합쳤다.
표기: [확인] = 페이지 본문/소스에서 직접 본 사실, [추정] = 조사자 해석·제안(출처 없음), (벤더) = 마케팅 벤더 블로그 수치로 검증 안 됨.
기존 100개와 겹치는 것(3D 플립 카드, 로드맵 pin, goo CTA, SVG 지도 핀드롭, FAQ 몰핑, 리뷰 월, 라벨모프 폼, 푸터 커튼+마그네틱, odometer)은 제외하거나 차별점을 명시했다.

## 0. 조사에서 확인된 큰 그림
- 국내 창업 페이지는 모션이 약하다. 빽다방/메가 비용 페이지/이디야 창업 페이지는 정적, bhc는 AOS fade-up(42곳), 컴포즈는 jquery.countup+waypoints+scrollreveal+Swiper 수준 [확인]. GSAP를 적극 쓰는 곳은 7번가피자(GSAP3.12.5·ScrollSmoother·SplitText·ScrambleText·three r128 등록 [확인], 본문 요소용인지는 미확정)와 슬로우캘리(GSAP3.11.4+ScrollTrigger+SplitType+Swiper11, 그누보드 기반 [확인]).
- 해외 대형 체인(Dunkin, Chick-fil-A, Jersey Mike's)도 정적 텍스트+카드 위주. Subway/Dutch Bros/Crumbl 등은 접속 불가·봇 차단으로 못 봄. Awwwards에 프랜차이즈 모집 전용 수상작은 검색되지 않음.
- 공통으로 강한 것은 "수치 증명" 콘텐츠: 매출 TOP N, 경쟁사 매장수 비교, 손익표, 다점포 비율, 대출 조건, 선착순 특가, 5~10단계 절차. 따라서 데이터 시각화·계산형 인터랙션이 전환에 가장 가깝다.
- 전환 주장(전부 (벤더) 수준, 프랜차이즈 단독 A/B 없음): 폼 앞에서 교육 후 폼 배치(업계 평균 전환 2.9%) / 단계형 폼 13.85% vs 4.53% / 계산기 페이지 19~24% / 영상 후기 +39~61% / 모바일 sticky CTA +18~20% / exit-intent는 유의 우위 없음(Popupsmart 28,674건 분석). 질문 순서는 쉬운 객관식 → 연락처 → 자금 순(자금 먼저 물으면 이탈).
- 법적 주의: 수익·투자 수치 시각화는 "예상치·보장 아님" 면책, 정보공개서(공정위) 근거 문구 필요. 국내 가맹사업법 표시광고 요건은 이번에 확인하지 못함.
