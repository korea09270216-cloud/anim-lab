## A. 스크롤 레이아웃 / 그리드

### 1. Elastic Grid Scroll (열마다 지연되는 탄성 스크롤)
- 효과: 그리드 각 열이 조금씩 다른 lag 로 따라와, 스크롤 시 그리드가 늘어났다 안정되는 탄성감.
- 구현 요점:
  - 그리드 아이템을 CSS 열 수에 맞춰 JS 로 열 단위로 그룹핑.
  - 열별 lag 를 "중앙으로부터의 거리"로 동적 계산(중앙열 0, 바깥열 큼).
  - ScrollSmoother `effects:true` 의 `data-lag` 로 구현. ScrollSmoother 없이 하려면 ScrollTrigger + 열별 `gsap.quickTo(y)` lerp 로 대체 가능 [추정].
- 난이도 ★★ / 부하 낮음 / 중복도: 낮음(007 은 양방향 반대 translate, 이건 lag 차등)
- 출처: https://tympanus.net/codrops/2025/06/03/elastic-grid-scroll-creating-lag-based-layout-animations-with-gsap-scrollsmoother/ (레포 codrops/ElasticGridScroll, 변형 index1~9)

- 구현 요점:

  - 메인 타임라인이 내부 타임라인 여러 개를 순서대로 조율(위상 phase 분리).
  - GSAP + ScrollTrigger(scrub) + Lenis. 위상별 세부 값은 본문 미확인 [추정].
- 난이도 ★★★ / 부하 낮음~중간 / 중복도: 낮음(063 은 sticky+scrub 타임라인이나 그리드 해체 아님)
